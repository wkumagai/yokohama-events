# カテゴリ体系と正規化ルール

イベント1件 = 主カテゴリ1つ + 横断タグ複数。

## 主カテゴリ（10種）

| id | 名称 | 含まれるもの |
|---|---|---|
| music | 🎵 音楽・ライブ | クラシック、コンサート、ジャズ、フェス |
| stage | 🎭 舞台・演劇・ダンス | 演劇、ミュージカル、コンテンポラリーダンス |
| traditional | 🏮 伝統芸能 | 能・狂言、落語・演芸、邦楽 |
| art | 🎨 アート・展覧会 | 美術展、ギャラリー、インスタレーション、芸術祭 |
| museum | 🏛 歴史・学び・ミュージアム | 博物館企画展、講座・講演、図書館、科学館 |
| festival | 🎪 祭り・季節行事 | 開港祭、馬車道まつり、春節、盆踊り、大道芸、神社祭事 |
| food | 🍺 グルメ・マルシェ | ビール祭、パン祭、マルシェ、物産展、ビアガーデン |
| night | ✨ イルミ・花火・夜間 | ミライト、ヨルノヨ、ナイトフラワーズ、ライトアップ |
| family | 👨‍👩‍👧 ファミリー・体験 | 子ども向けワークショップ、体験教室、参加型企画 |
| sports_other | 🏟 スポーツ・その他 | 野球、大会、マラソン、展示会・即売会、ポップアップ |

## 横断タグ

- 料金: `free` / `paid` / `partially_free`
- 場所柄: `outdoor` / `indoor`（雨の日フィルタ用）
- 参加条件: `no_reservation` / `reservation_required` / `kids_ok`
- 期間性: `one_day` / `long_run`（展覧会等） / `annual`（毎年恒例）

## 情報源カテゴリ → 主カテゴリ マッピング（抜粋）

| 情報源の分類 | → 主カテゴリ |
|---|---|
| アートナビ「音楽」 | music |
| アートナビ「舞踏・演劇」 | stage |
| アートナビ「古典芸能」「大衆芸能」 | traditional |
| アートナビ「美術」「写真・映像」「文芸」 | art |
| 赤レンガ1号館「ダンス/演劇」 | stage |
| 赤レンガ1号館「音楽」 | music |
| 赤レンガ1号館「アート/トーク」 | art / museum |
| welcome.city「祭り・催し」 | festival |
| welcome.city「グルメ」 | food |
| 施設固定: 能楽堂・にぎわい座 | traditional |
| 施設固定: みなとみらいホール・音楽堂・Kアリーナ・ぴあアリーナ | music |
| 施設固定: KAAT・関内ホール(既定値) | stage |
| 施設固定: 美術館・ギャラリー・BankART・象の鼻 | art |
| 施設固定: 博物館・資料館・図書館・ニュースパーク | museum |
| 施設固定: カップヌードル・三菱技術館・原鉄道 | family |
| 施設固定: 神社仏閣の祭事 | festival |

マッピングで決まらない場合はタイトルのキーワード判定
（「ビール|マルシェ|グルメ|物産展」→ food、「イルミ|花火|ライトアップ」→ night、
「落語|寄席」→ traditional、「こども|親子|ワークショップ」→ family 等）。
それでも不明なら sports_other に落とし、`data/overrides.json` で手動補正できるようにする。
